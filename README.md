## Engineering approach

- **Start with the workflow.** I prefer understanding the domain, users, data, and constraints before choosing abstractions.
- **Design for change.** Typed boundaries, clear modules, explicit migrations, tests, and CI matter more than clever code.
- **Treat UI as part of the system.** Accessibility, information hierarchy, responsive behavior, and operational usability are engineering concerns too.
- **Use AI as leverage, not as a substitute for judgment.** I use AI-assisted workflows for implementation, analysis, research, QA, and automation while keeping the system inspectable.
